# DEC-0008 — Ativar primeiro o caminho crítico

**Decisão:** construir a arquitetura completa, mas **ativar** inicialmente `A0 → A1 → A2 → A3 → A4 → A6 → A7 → A8 → A10 → A0`. Depois A5 (aquisição) e A9 (parcerias) entram para escala.
**Primeira entrega:** CORE v0.1 ([[CORE-v0.1]]).
**Alternativa rejeitada:** esperar centenas de workflows para validar a primeira máquina.
**Observação:** no roadmap canônico ([[roadmap]]), M03 valida A0–A4 e M04 valida A5–A10. A ordem de ativação deste DEC (A6, A7, A8, A10 antes de A5 e A9) vale dentro do M04, confirmado em [[DEC-0015-alocacao-do-roadmap-m01-m04]] (P10). O Create Launch usa o A6, então um A6 mínimo entra no M03.
