# Critério de sucesso da primeira versão

A v1 é funcional quando o sistema consegue (Blueprint §47):
```text
CRIAR PRODUTO → CRIAR OFERTA → CRIAR LAUNCH
→ A1 analisa mercado → A2 estrutura oferta/produto → A3 gera plano de comunicação
→ A4 configura audiência → A6 prepara lançamento → HUMAN APPROVAL → LAUNCH_READY
```
Depois:
```text
OPEN CART → ORDERS → CUSTOMERS → POST LAUNCH → ANALYTICS → LEARNING → NEXT LAUNCH
```

Fluxo completo do Plano Final §26 (espinha dorsal da PLF): criar produto → analisar mercado → criar oferta → criar plano → pré-pré → PLC 1, 2, 3 → configurar CRM → configurar campanhas → QA → abrir carrinho → monitorar → fechar → pós-venda → analisar → aprender.

> Quando esse fluxo funcionar de ponta a ponta, deixamos de ter um blueprint e passamos a ter o primeiro núcleo operacional.

Teste de aceite em ambiente de teste: primeiro `INTERNAL LAUNCH` (Blueprint §40, passo 15), com lançamento **simulado**.
